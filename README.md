# 大道总纲——段永平资料合集（EPUB）

本仓库提供电子书 `dist/大道总纲.epub`，可直接用任意 EPUB 阅读器（Calibre、静读天下、Apple Books、Kindle 推送等）打开。

## 内容来源

全书内容整理自公开网站 [duan.ayaseeri.com](https://duan.ayaseeri.com/)（段永平资料合集站），共 157 篇文章，按九大分类编排：

- 访谈实录
- 投资问答录
- 核心哲学
- 投资理念
- 企业经营
- 品格与心性
- 财务指标
- 公司与人物
- 推荐书单

电子书保留了原站的目录层级与文内交叉链接：站内链接已重写为 EPUB 内部跳转，外站链接（京东、雪球等）保留原样。
